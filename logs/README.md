# Logs Directory

Ce dossier contient les journaux de sécurité de l'application.

## Fichiers

- `security.log` - Événements de sécurité (connexions, déconnexions, tentatives échouées, etc.)

## Important

- Ne pas inclure ces fichiers dans le versioning (déjà dans .gitignore)
- Nettoyer régulièrement les logs anciens
- Protéger l'accès à ce dossier en production
